# Uber Redesign — Process Journal

Static GitHub Pages site for explaining the workflow behind the Uber Groups redesign: framing the opportunity, comparing directions, mapping the customer journey, prototyping with multiple AI roles, and reflecting on AI-assisted design.

## Publish with GitHub Pages

Upload `index.html`, `style.css`, `app.js`, `.nojekyll`, and `README.md` to the repository root. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. No build command is required.
